# П2: runtime SQLite — итог синтетической приёмки

Дата итога: 17.11.2026. Незакоммиченные изменения; коммит, публикация и миграция
не выполнялись.

## Результат

Синтетическая приёмка П2 пройдена. SQLite runtime доступен после явной
инициализации новой БД и проверки единственной активной identity. Умолчание
остаётся `legacy_files`. Реальные и старые данные нельзя подключать до П5 и
отдельно согласованной миграции.

Проверен сквозной сценарий `worker.main` → правка → review → подтверждённый
ответ → отмена → конспект → чтение/правка по `recording:<UUID>` без job.
Ответ, transcript и review фиксируются одной транзакцией; отказ commit и
конкурентное изменение не создают частичного применения. Повтор после сбоя
материализации доводит документы до актуального состояния без повторного
применения ответа. Импортированный ответ сохраняет неизвестное авторство и
требует отдельного подтверждения; свободный импортированный текст нужно заново
ввести в локальной карточке.

Проверены конфликты внешних документов и конспектов: данные сохраняются,
разрешение проходит через штатное подтверждение, повторная проверка хэша не
перезаписывает последующую внешнюю правку. При выбранном SQLite недоступная БД
или незарегистрированный файл не переводят запись на legacy-писатель.
Голосовое обучение SQLite-записей явно блокируется до authoritative DB API.

- Свободный ответ неизвестного происхождения нельзя подтвердить через MCP;
  его следует заново ввести в локальной карточке.
- Обучение голосового профиля по SQLite пока не поддерживается.
- Файлы и база не переносились; реальные записи, HF-сеть и профили не
  использовались. Коммит и публикация не выполнялись.
